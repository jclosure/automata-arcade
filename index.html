Script Kernel — Command Mode

Press Escape inside a cell to enter command mode (blue highlight). Press Enter to edit.

  • Enter Edit selected cell
  • Shift+Enter Run + select below
  • Ctrl+Enter Run in place
  • ↑ / K Select cell above
  • ↓ / J Select cell below
  • A Insert cell above
  • B Insert cell below
  • D D Delete selected cell
  • Z Undo delete
  • X Cut cell
  • C Copy cell
  • V Paste below
  • Shift+V Paste above
  • O Toggle output
  • L Toggle line numbers
  • I I Pause / resume hooks
  • 0 0 Clear cell output
  • Escape Exit command mode
